## ✦ Overview

This repository contains the complete source code, assets, and design system for the personal portfolio of **Chaitanya Toraskar**. 

Engineered with a focus on dark-mode luxury aesthetics, refined typography, and hardware-accelerated animations, this portfolio reflects my work across **Full-Stack Software Engineering**, **Data Analytics & Business Intelligence**, and **Applied Artificial Intelligence**.

---

## ⚡ Highlights & Key Features

- **Multilingual Staircase Preloader:** Fluid greeting sequence cycling through English, Malayalam, Hindi, Marathi, and Spanish (`Hello.`, `നമസ്കാരം.`, `नमस्ते.`, `नमस्कार.`, `hola!`) transitioning into a 4-column staggered upward wipe.
- **Interactive Character Avatar:** Custom-crafted anime avatar with responsive touch and hover smile & blush state transitions (`avatar.png` & `blush.png`).
- **Hardware-Accelerated Star Shower:** Top nav star button (`☆`) triggering a 60/120 FPS compositor-thread star cascade (`✦`) with zero layout reflow or frame lag.
- **Interactive Highlights Carousel:** Swipe-friendly project carousel displaying 6 live project demo mockups with touch support and arrow navigation.
- **Dynamic Category Filter Pills:** Real-time filter system for projects categorized into `dev`, `data & bi`, and `ai & sys`.
- **Dedicated About Me Page:** Custom page featuring curved *"Who am i?"* typography in *Instrument Serif*, personal tech journey, teaching experience, and nature photography.
- **Interactive CLI Badge:** `% npx chaitanya` pill with one-tap clipboard copy and animated feedback tooltip.
- **100% Mobile Responsive:** Zero horizontal layout shift (`scrollWidth === innerWidth`) tested on viewports from 360px up to 4K displays.

## 🚀 Running Locally

To run this portfolio locally on your machine:

```bash
# 1. Clone the repository
git clone https://github.com/chaitanyachaitanyatoraskar-svg/chaitanya.git

# 2. Navigate to the project directory
cd chaitanya

# 3. Start a local HTTP server (Python 3)
python3 -m http.server 3000

# 4. Open in browser
open http://localhost:3000
```
